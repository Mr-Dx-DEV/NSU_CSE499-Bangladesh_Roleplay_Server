## Technical Notes for Demo

### Commands to Know:
```
/admin - Admin menu
/car [model] - Spawn vehicle (admin)
/coords - Show coordinates
/dv - Delete vehicle
/job - View current job
/setjob [id] [job] - Set player job
/garage - Open garage
/logout - Character selection
```

### Common Issues & Fixes:
1. **Character stuck:** Use /revive or /respawn
2. **Vehicle issues:** Use /dv to delete
3. **Job not working:** Re-assign job with /setjob
4. **Phone not opening:** Restart resource or relog
5. **Voice not working:** Check pma-voice resource
